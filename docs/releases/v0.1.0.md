dunes-ledger keeps two numbers apart after a farming session: what the whole session made, and what a typical map made. One click on the most profitable map shows the drop behind the difference.

## What you can do with 0.1.0

- Record maps as you finish them: cost, minutes (or the built-in timer) and loot lines. Enter adds a line, Ctrl+Enter finishes the map, and the previous map's cost is filled in for the next one.
- Read the session net next to the median net per map, with gross value, map costs, elapsed minutes, chaos per hour and the currency.
- Click the most profitable map to see its loot lines and how much of its lead one drop accounts for.
- Leave a price blank when you don't know it: the totals then say "priced loot only" and count what was left out. A price of 0 stays 0.
- Edit or delete finished maps. Later price-list changes never rewrite a finished session, because each loot line keeps the price it was recorded with.
- Export a session to versioned JSON and import it into another browser. A bad file is refused whole, re-importing the same data changes nothing, and conflicting content waits for your choice.
- Keep using it offline after the first visit, and install it as a web app from the browser.

## Install

Download `dunes-ledger-0.1.0-site.zip`, unzip it, and serve the `dunes-ledger-0.1.0` folder with any static web server, for example:

```sh
cd dunes-ledger-0.1.0
python -m http.server 4173
```

Then open <http://localhost:4173/> and choose **Load the synthetic sample**, or import `synthetic-dunes-session.json` from this release. Opening `index.html` straight from disk does not work, because browsers run service workers only over `http://localhost` or `https://`.

`dunes-ledger-0.1.0-pages.zip` is the same app built for `https://<owner>.github.io/dunes-ledger/`, ready to upload as a GitHub Pages site. `SHA256SUMS.txt` lists the checksums of all three files.

The sample session is synthetic: invented round numbers that make the arithmetic easy to check (120 chaos net, a median of 2 chaos per map, 144 chaos per hour). It is not a statement about real drop rates or prices.

## Known limitation

Prices are typed by hand; there is no market lookup. If the price list is out of date, the session net is wrong and nothing warns you. Only prices that are missing altogether are flagged.
